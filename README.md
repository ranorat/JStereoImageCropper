# JStereoImageCropper

●本ソフトについて  
・立体視用の左右２つの画像を読み込み、４辺を切り落とし微調整するGUIツールです。  
・左右２枚の画像を同時にクロップします。同じ方向の辺および対象の辺で同時クロップします。  
・左右の画像を入れ替え(平行法・交差法)て表示確認ができます。  
・画像は３枚(左・右・左右結合)で出力されます。左右結合画像のみ補助点有無が選択できます。  

●実行方法・環境について  
・Javaソフトであるため、予めJRE（Java実行環境）のインストールをしてください。  
　　①jarファイルをダブルクリックして実行。  
　　②プロンプトでjar本体のある階層に移動して下記コマンドで起動  
     cd "jarファイルの存在するフォルダ階層"  
     java -jar JStereoImageCropper.jar  
　・GUI起動後、立体視用の２つの画像を選択しD＆Dで読み込みます。  
　・２つの画像の解像度が異なる場合、画像を読み込むことができません。  

・Windowsにて開発・テストしています。Javaのため実行環境は選びませんが  
　ほかのOSにて動作確認はしていません。  
・コンパイラ：Microsoft OpenJDK version "25.0.4" 2026-07-21 LTS
